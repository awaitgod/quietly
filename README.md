# quietly desktop

quietly это мессенджер для компьютера. здесь можно общаться в личных и групповых чатах, отправлять стикеры и подарки, слушать музыку и настраивать свой профиль.

приложение сделано на vue и tauri. часть данных хранится на компьютере, а для работы с аккаунтом и сообщениями используется supabase.

## что нужно для запуска

- node.js и pnpm
- rust 1.90 или новее
- на windows: инструменты сборки microsoft c++ и webview2

## как запустить

установите зависимости:

```sh
pnpm install
```

запустите приложение на компьютере:

```sh
pnpm tauri dev
```

чтобы открыть интерфейс в браузере:

```sh
pnpm dev
```

в браузере некоторые функции приложения могут быть недоступны.

## как собрать

```sh
pnpm tauri build
```

готовые файлы для установки появятся в папке `src-tauri/target/release/bundle`.

проверить сборку интерфейса можно так:

```sh
pnpm build
```

проверить код приложения на rust:

```sh
cargo test --manifest-path src-tauri/Cargo.toml
```

## где что лежит

- `src/components` содержит окна и элементы интерфейса
- `src/stores` хранит состояние приложения
- `src/services` отвечает за связь с сервером и приложением на компьютере
- `src-tauri/src` содержит код tauri, работу с локальной базой и системным треем
- `public` содержит картинки, стикеры и другие файлы приложения

## подключение к серверу

настройки supabase находятся в `src/services/supabase.ts`. приложение подключено к существующему проекту supabase. для работы с другим сервером нужно настроить его отдельно и изменить эти параметры.
